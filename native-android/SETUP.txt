ANDROID DOWNLOADS PLUGIN — IMPORTANT FOR THE FINAL APK

The original CITS3200-38 GitHub repo contains no tracked android/ project.
This Java source must be copied into the actual Capacitor Android project
that Hannah/Owen is packaging; adding only the JS files to GitHub is not enough.

Place OsteoMapDownloadsPlugin.java into the same Java package/folder as
android/app/src/main/java/.../MainActivity.java.
Change its `package com.cits3200.osteomaptest;` line to your actual application
package if different.

Register in MainActivity.java before calling super.onCreate(...):

    @Override
    public void onCreate(Bundle savedInstanceState) {
        registerPlugin(OsteoMapDownloadsPlugin.class);
        super.onCreate(savedInstanceState);
    }

You may need `import android.os.Bundle;`. Keep existing MainActivity code.

Then from the Capacitor project root:
    npx cap sync android

Rebuild/reinstall the APK in Android Studio (sync alone does not rebuild).
The custom Java plugin writes files into public Downloads on Android 10+.
No ZIP is produced. Both checkboxes selected -> two distinct files.
The previous Share/Filesystem plugins are NOT required for Android Downloads.
Desktop browsers continue normal browser downloads.

Do not copy the native-android/ folder verbatim as `android/` inside the web
repository. Its Java source must be integrated into the generated Android app.

ANDROID LAUNCHER ICON — TESTED IN ANDROID EMULATOR

The source artwork is native-android/OsteoMap_App_Icon_1024.png.
Launcher resources are tracked under native-android/launcher-res/res/.

In the Android packaging project, copy the contents of that res/ folder
into android/app/src/main/res/ (merge folders, overwriting the default
ic_launcher resources). For example, from the Git repository root:

    rsync -a native-android/launcher-res/res/ \
      /path/to/CapacitorProject/android/app/src/main/res/

Keep the existing app's AndroidManifest icon reference to @mipmap/ic_launcher.
Build a fresh APK and verify the icon on an emulator and physical Android phone.
Capacitor sync alone does not copy launcher-res resources from this repository.
The final app ID and signing configuration belong to the final build project;
the test ID com.cits3200.osteomaptest is not the client release identity.
